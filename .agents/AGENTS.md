# AI Coding Agent Bootstrap

Before making any code changes, every AI coding agent MUST complete the following bootstrap sequence:

1. Read `docs/PROJECT_CONTEXT.md` to understand the project goals, scope, and success criteria.
2. Read `docs/ARCHITECTURE.md` to understand the system architecture, component responsibilities, and data flow.
3. Read `docs/AGENT_RULES.md` to understand the mandatory implementation rules.
4. Read the current phase specification under `docs/phases/` before implementing any feature.

## Rule Priority

`docs/AGENT_RULES.md` is the single authoritative source for all implementation rules and coding standards.

Unless explicitly instructed by the user, these rules MUST NOT be overridden or duplicated elsewhere in the codebase.
